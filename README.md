# Zepnest Customer App: Design Reference

Icons, brand marks, illustrations, colours, type and component recipes from the Zepnest customer app.

**→ Start with [design.md](design.md).**

- `assets/brand/`: logo (PNG + reversed SVG)
- `assets/app-icons/`: favicons, PWA and Apple touch icons, web manifest
- `assets/categories/`: 8 glossy 3D category illustrations (WebP, 512 px)
- `assets/service-cards/`: 23 service photos (WebP, 640 px) + placeholder SVG

All UI icons are **Font Awesome 6.4.0 Free (Solid)**. The full name-to-glyph map is in design.md §2–3.
